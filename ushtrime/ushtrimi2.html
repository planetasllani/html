Inside the header, add a navigation menu with two links: "Home" and "Gallery." 4. Create a `main` element and divide it into two sections. 5. In the first section, use the `picture` tag to display an image. Provide multiple sources with different resolutions for better responsiveness. 6. In the second section, create a list of bookmarks related to your favourite topics. Each bookmark should link to a specific section within the same webpage.
